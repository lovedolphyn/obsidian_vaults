As of 04/29/26, Josh Plunkett showed me a way to import all my sourcebooks and adventure data from DnD Beyond using CLI. **Note: DO NOT use the actual CLI folder or pages for creating adventures. It should be considered READ ONLY.** Instead, create new folders in your Worlds folder, then create new pages of notes for your adventures. You should create an adventure folder with a page for each of your players, NPCs, mobs, interactive maps, etc. You can pull into info from the CLI folder so you don't have to retype everything (example below).

>[!tip] Also, Josh suggests creating a landing page for each adventure with quick DM tools and pin this page; create an interactive map that you can pin and access in your left panel (so you can click and view pins to just directly to your notes without having to swap back and forth between info and map); and using the right panel for running both encounters and viewing mob's stat blocks. I also think adding all the encounters as a table on your DM landing page is an awesome idea.
